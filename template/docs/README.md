# docs

Design, acceptance criteria and defects of this project.

- `design.md` - how the firmware is put together and why
- `acc-crit-{{ repo_name }}.md` - behaviour the firmware must show, with the test that proves it
- `defects-{{ repo_name }}.md` - defects, their root cause and their evidence

The two tracker files are written only through the `pm-tools` CLI, never by hand.
